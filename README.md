# Methods of Representation Theory, Volume I

Charles W. Curtis and Irving Reiner,
*Methods of Representation Theory, with Applications to Finite Groups and
Orders*, Volume I, Wiley, 1981.

Typst sources, a PDF of the book with editorial notes, and a separate list
of corrections. Bibliographic descriptions are generated from BibLaTeX;
the subject index is generated from semantic marks in the text.

The book and corrections PDFs are available in
[Releases](https://github.com/stdcall/curtis-repr.1/releases/latest).

Build with `just build`; run the complete validation with `just check`.
The PDF files are written to `build/`.
